# Vynix Skill Library

Skills are workflow playbooks for agents using this MCP server.

## Included skills

- review-website.md
- critical-issues.md
- open-feedback.md
- summarize-feedback.md
- sprint-report.md
- engineering-tasks.md
- accessibility-review.md
- ux-review.md
- release-readiness.md
- qa-summary.md
- regression-summary.md
- client-approval-summary.md
- pm-briefing.md

Each skill is designed as an end-to-end sequence:

1. Discover project
2. Pull scoped annotations
3. Drill into context
4. Produce output artifact
5. Optionally update status/comments
