# Contributing to Vynix MCP Server

Thanks for your interest in improving Vynix MCP Server, part of the [Vynix](https://vynix.in) toolkit.

## Development setup

```bash
git clone https://github.com/UseVynix/vynix-mcp.git
cd vynix-mcp
npm install
npm run build
```

## Validation

Run the full local check suite before opening a pull request:

```bash
npm run check
```

This runs linting, type checks, smoke tests, and example config validation.

## How to help

- Open an issue for bugs or ideas.
- Send a pull request for focused fixes and improvements.
- Improve documentation, examples, prompts, and workflow quality.

## Ground rules

- Keep changes focused and well described.
- Preserve backward compatibility for tool names and semantics when possible.
- Add or update tests/docs for behavior changes.
- Be kind in reviews and discussions.

For product feedback about Vynix itself, the fastest path is to use Vynix on your own site at [https://vynix.in](https://vynix.in).
